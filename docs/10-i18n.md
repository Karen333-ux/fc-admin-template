# ١٠ — الترجمة والتوطين (عربي / إنجليزي)

## المبدأ

> **صفر نص مكتوب في الكود.** أي حرف المستخدم يشوفه لازم يكون في ملف ترجمة، بالعربي وبالإنجليزي.

اللغة الافتراضية **عربي**، والاحتياطية **إنجليزي**.

---

## ١. بنية ملفات الترجمة

الترجمة موزّعة على السياقات — مش ملف عملاق واحد:

```
lang/
├── ar/
│   ├── common.php          # مشترك: حفظ، إلغاء، حذف، تأكيد...
│   ├── navigation.php      # المجموعات والعناصر
│   ├── authorization.php   # الصلاحيات والأدوار
│   ├── table.php           # نصوص الجداول
│   ├── settings.php
│   ├── validation.php      # رسائل التحقق (من Laravel-lang)
│   └── ...
├── en/  (نفس الملفات)
└── ...

src/Contexts/Identity/Lang/
├── ar/identity.php
└── en/identity.php
```

السياق بيسجّل ملفاته:

```php
$this->loadTranslationsFrom(__DIR__ . '/Lang', 'identity');
// الاستخدام: __('identity::identity.fields.name')
```

> **قرار:** للتبسيط على الإنترن، نستخدم namespace واحد `identity` (مش `identity::identity`). سجّلها كـ:
> ```php
> $this->loadJsonTranslationsFrom(__DIR__ . '/Lang');  // لا
> // بدلها انسخ لملف lang/{locale}/identity.php عبر publish، أو استخدم:
> $this->loadTranslationsFrom(__DIR__ . '/Lang', 'identity');
> ```
> واستدعِ `__('identity::identity.fields.name')`. الشكل ده أوضح وبيمنع تصادم المفاتيح.

## ٢. رسائل التحقق العربية

```bash
composer require laravel-lang/common --dev
php artisan lang:add ar
php artisan lang:update
```

بيجيب كل رسائل Laravel وFilament مترجمة عربي جاهزة. راجعها وعدّل اللي مش عاجبك — الترجمات الآلية أحياناً ركيكة.

## ٣. ترجمة محتوى قاعدة البيانات

للحقول اللي محتواها نفسه مترجم (اسم المؤسسة، عنوان المقال):

```bash
composer require spatie/laravel-translatable:^6.14
```

```php
use Spatie\Translatable\HasTranslations;

class Tenant extends Model
{
    use HasTranslations;

    public array $translatable = ['name', 'description'];
}
```

الميجريشن: `$table->json('name');`

في Filament:

```php
Tabs::make('translations')
    ->tabs(collect(config('app.supported_locales'))->map(
        fn (string $locale) => Tabs\Tab::make($locale)
            ->label(__("common.locales.{$locale}"))
            ->schema([
                TextInput::make("name.{$locale}")
                    ->label(__('tenancy.fields.name'))
                    ->required($locale === config('app.fallback_locale')),
            ])
    )->all())
    ->columnSpanFull();
```

> **قاعدة:** اللغة الاحتياطية (`en`) إجبارية، الباقي اختياري مع fallback.

## ٤. تبديل اللغة

```php
// config/app.php
'supported_locales' => ['ar', 'en'],
```

```php
final class SwitchLocaleAction
{
    public function handle(string $locale): void
    {
        abort_unless(in_array($locale, config('app.supported_locales'), true), 400);

        auth()->user()?->update(['locale' => $locale]);
        session()->put('locale', $locale);

        // ما ينفعش نعتمد على السيشن بس — الطوابير محتاجة الـ DB
    }
}
```

ميدلوير:

```php
final class SetLocale
{
    public function handle(Request $request, Closure $next): Response
    {
        $locale = auth()->user()?->locale
            ?? session('locale')
            ?? app(GeneralSettings::class)->default_locale;

        app()->setLocale($locale);
        Carbon::setLocale($locale);

        return $next($request);
    }
}
```

سجّله في `->middleware([SetLocale::class], isPersistent: true)` على اللوحة.

## ٥. الاتجاه (RTL)

> ⚠️ **مفيش دالة `->direction()` على الـ Panel.** الاتجاه بيتحدد من ملف ترجمة Filament نفسه:

```bash
php artisan vendor:publish --tag=filament-panels-translations
```

```php
// lang/vendor/filament-panels/ar/layout.php
return ['direction' => 'rtl', /* ... */];
```

كرّر ده لكل حزم Filament المستخدمة (`filament-forms`, `filament-tables`, `filament-actions`, `filament-notifications`). التفاصيل في `docs/06-theme-branding.md` بند ٨.

### ما يتفحَص يدوياً في كل شاشة

| العنصر | المطلوب |
|---|---|
| الأيقونات الاتجاهية | سهم «رجوع» و«التالي» ينعكسوا |
| الحشو والهوامش | `ps-`/`pe-` مش `pl-`/`pr-` |
| الحدود | `border-s`/`border-e` |
| المحاذاة | `text-start`/`text-end` |
| الرسوم البيانية | المحور الرأسي على اليمين |
| شريط التقدّم | يملا من اليمين |
| الجداول | العمود الأول على اليمين |
| القوائم المنسدلة | تفتح ناحية اليمين |

### أكواد لاتينية جوه نص عربي

```blade
<span class="fc-code">{{ $user->code }}</span>
```
```css
.fc-code { unicode-bidi: isolate; direction: ltr; display: inline-block; }
```

من غير كده، `USR-1024` هيظهر `1024-USR` جوه جملة عربية.

## ٦. الأرقام والتواريخ والعملة

```php
// helpers.php
function fc_number(int|float $value, int $decimals = 0): string
{
    // أرقام لاتينية في الواجهة دايماً — حتى بالعربي
    return number_format($value, $decimals, '.', ',');
}

function fc_currency(int|float $amount, string $currency = 'EGP'): string
{
    return __("common.currency.{$currency}", ['amount' => fc_number($amount, 2)]);
}

function fc_date(?Carbon $date, string $format = 'd M Y'): string
{
    return $date?->locale(app()->getLocale())->translatedFormat($format) ?? '—';
}
```

### القواعد
- **أرقام لاتينية (0–9) في الواجهة** — الأرقام الهندية (٠–٩) في المستندات المطبوعة بس
- **التقويم الميلادي** افتراضياً، والهجري كإعداد اختياري
- **المنطقة الزمنية** `Africa/Cairo` مخزّنة UTC ومعروضة محلي
- **العملة** الرمز بعد الرقم في العربي: `1,250.00 ج.م`

## ٧. الجمع (Pluralization)

العربي فيه ٦ صيغ جمع مش اتنين:

```php
// lang/ar/common.php
'results' => '{0} لا توجد نتائج|{1} نتيجة واحدة|{2} نتيجتان|[3,10] :count نتائج|[11,*] :count نتيجة',
```

```php
trans_choice('common.results', $count, ['count' => fc_number($count)]);
```

> **معيار قبول:** جرّب بالقيم 0, 1, 2, 5, 11, 100 — كلها لازم تطلع صح عربي.

## ٨. اختبارات الترجمة (إلزامية)

```php
it('كل مفاتيح الترجمة العربية لها مقابل إنجليزي', function () {
    $ar = collect(File::files(lang_path('ar')));

    foreach ($ar as $file) {
        $arKeys = Arr::dot(require $file->getPathname());
        $enPath = lang_path('en/' . $file->getFilename());

        expect(File::exists($enPath))->toBeTrue("ناقص: {$file->getFilename()} بالإنجليزي");

        $enKeys = Arr::dot(require $enPath);
        $missing = array_diff_key($arKeys, $enKeys);

        expect($missing)->toBeEmpty(
            "مفاتيح ناقصة في en/{$file->getFilename()}: " . implode(', ', array_keys($missing))
        );
    }
});

it('لا يوجد نص مكتوب مباشرة في ملفات Blade', function () {
    $violations = [];

    foreach (File::allFiles(resource_path('views')) as $file) {
        $content = $file->getContents();
        // نص عربي بره __() أو {{ }}
        if (preg_match('/>\s*[\x{0600}-\x{06FF}]{3,}/u', $content)) {
            $violations[] = $file->getRelativePathname();
        }
    }

    expect($violations)->toBeEmpty('نصوص عربية مكتوبة مباشرة في: ' . implode(', ', $violations));
});

it('لا توجد فئات CSS اتجاهية', function () {
    $pattern = '/\b(pl|pr|ml|mr|border-l|border-r|text-left|text-right|left|right)-\d/';
    // ... نفس النمط على resources/views و src/**/Presentation
});
```
